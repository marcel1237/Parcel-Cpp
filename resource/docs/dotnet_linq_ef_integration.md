# .NET Framework, LINQ & Entity Framework Integration Documentation

## 📋 Overview
Parcel C++ includes comprehensive integration for **.NET Framework / .NET Core APIs**, enabling high-level data manipulation with **LINQ** query operators and relational database mapping via **Entity Framework Core** (`[DotNetIntegrationService.hpp](file:///home/marcel/Parcel-Suite/Parcel%20C++/src/service/DotNetIntegrationService.hpp)`).

---

## 🚀 Key Features

1. **LINQ Query Operators Bridge:**
   - Provides expression tree and query syntax bridging for filtering, sorting, and projecting collections across multi-language workflows in the IDE.

2. **Entity Framework Core (EF Core) ORM & DbContext:**
   - Scaffolds database contexts (`DbContext`) and entity mappings for relational persistence (SQLite, PostgreSQL, SQL Server).

3. **IDE Configuration & Status:**
   - Fully integrated into the IDE Settings view (`[SettingsView.hpp](file:///home/marcel/Parcel-Suite/Parcel%20C++/src/view/SettingsView.hpp)`), displaying active .NET 8/9 and ORM bridge status.
