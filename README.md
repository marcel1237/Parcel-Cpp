# Parcel C++

**Parcel C++** is a sophisticated, AI-driven Industrial Development Toolkit built on **Qt 6**. It integrates multi-agent intelligence, real-time code auditing, and a visual UI designer to streamline complex C++ and Shell Scripting workflows.

---

## 🚀 Key Features

### 🧠 SS AI Agent (Extraordinary Shell Intelligence)
- **Multi-Agent Orchestration:** Seamlessly triages requests between local semantic analysis, real-time web research, and deep reasoning via LLMs (Gemini & OpenAI).
- **SSQLM Standards:** Enforces high-fidelity Shell Script Quality Language Model (SSQLM) standards for safety, atomicity, and industrial resilience.
- **Deep Technical Research:** Synthesizes implementation patterns from multiple technical sources (GitHub, StackOverflow, CppReference) automatically.

### 🎨 Visual UI Designer & Blueprint Engine
- **Hybrid Bridge:** Advanced C++/QML bridge for visual interface development with Kirigami support.
- **Blueprint Engine:** Design complex logic flows visually and generate optimized QML/C++ code in real-time.
- **Cyber-Dark Theme:** Professional, high-contrast dark aesthetic optimized for long-duration industrial development.

### 🛡️ Core Services & Safety
- **Backup Service:** Incremental, SQLite-based project versioning and safe restoration points.
- **Script Validator:** Real-time linting for Shell scripts to prevent common pitfalls and security risks.
- **Persistence Layer:** Encrypted storage for API keys and project session management.

## 🛠️ Build & Installation

### Prerequisites
- **Qt 6.x** (Widgets, WebEngine, Quick, Sql, Charts, Network)
- **CMake 3.16+**
- **Python 3.10+** (with `genai`, `openai`, `trafilatura`, `scikit-learn` in a venv)
- **ShellCheck** (for script auditing)

### Build Instructions
```bash
# Clone the repository
git clone https://github.com/your-repo/parcel-cpp.git
cd parcel-cpp

# Run the build script
./build.sh
```

### Running the Application
```bash
./build/run.sh
```
